# 🚀 Система управления снабжением

Полнофункциональная веб-система для управления заявками на снабжение строительных объектов с современным интерфейсом и REST API.

## ✨ Ключевые возможности

### 📋 Управление заявками
- ✅ Создание и редактирование заявок на снабжение
- ✅ Отслеживание статусов (Новая, В работе, Ожидает поставки, Выполнена, Отменена)
- ✅ Система приоритетов (Низкий, Средний, Высокий, Критический)
- ✅ Сроки выполнения с визуальными индикаторами
- ✅ История изменений статусов

### 🏢 Управление данными
- ✅ База поставщиков с контактной информацией
- ✅ База строительных объектов
- ✅ Связи между заявками, поставщиками и объектами
- ✅ Поиск и фильтрация по всем параметрам

### 🔌 REST API
- ✅ Полный REST API для интеграции
- ✅ CRUD операции для всех сущностей
- ✅ Фильтрация, пагинация и поиск
- ✅ Статистика и health checks

### 📊 Продвинутые функции
- ✅ Система уведомлений (email, Slack)
- ✅ Кеширование для производительности
- ✅ Логирование всех операций
- ✅ Паттерн Наблюдатель для реактивности

## 🚀 Быстрый старт

### Требования
- Python 3.8+
- pip (устанавливается вместе с Python)

### Установка и запуск

```bash
# 1. Клонируйте репозиторий
git clone <repository-url>
cd supply-management-system

# 2. Установите зависимости
pip install -r requirements.txt

# 3. Запустите приложение
python run.py
```

### 🎯 Что произойдет после запуска:
1. ✅ Автоматически создастся база данных SQLite
2. ✅ Заполнится демо-данными (поставщики, объекты, заявки)
3. ✅ Приложение будет доступно на http://localhost:5000

## 📱 Использование

### Веб-интерфейс
- **Главная страница**: Статистика и быстрый доступ
- **Заявки**: Управление заявками с фильтрами
- **Поставщики**: База поставщиков
- **Объекты**: Строительные объекты

### API для интеграции
```bash
# Получить все заявки
curl http://localhost:5000/api/v1/requests

# Создать новую заявку
curl -X POST http://localhost:5000/api/v1/requests \
  -H "Content-Type: application/json" \
  -d '{"title": "Цемент М500", "quantity": "50", "unit": "тонн"}'

# Получить статистику
curl http://localhost:5000/api/v1/stats
```

## 🎭 Демо-данные

При первом запуске автоматически создаются:

- **5 поставщиков** (СтройМатериалы Про, МеталлТорг, и др.)
- **5 строительных объектов** (ЖК Солнечный, БЦ ТехноПарк, и др.)
- **8 заявок** с разными статусами и приоритетами

## 📊 API Endpoints

| Метод | Endpoint | Описание |
|-------|----------|----------|
| GET | `/api/v1/requests` | Список заявок с фильтрами |
| POST | `/api/v1/requests` | Создать заявку |
| GET | `/api/v1/requests/{id}` | Детали заявки |
| PUT | `/api/v1/requests/{id}` | Обновить заявку |
| DELETE | `/api/v1/requests/{id}` | Удалить заявку |
| GET | `/api/v1/suppliers` | Список поставщиков |
| GET | `/api/v1/sites` | Список объектов |
| GET | `/api/v1/stats` | Статистика |
| GET | `/api/v1/health` | Health check |


