# Система управления снабжением

Веб-приложение для отслеживания заявок на снабжение строительных объектов.

## Возможности

- ✅ Создание и управление заявками на снабжение
- ✅ Отслеживание статусов заявок (Новая, В работе, Ожидает поставки, Выполнена, Отменена)
- ✅ Управление приоритетами (Низкий, Средний, Высокий, Критический)
- ✅ Ведение базы поставщиков
- ✅ Ведение базы строительных объектов
- ✅ История изменений статусов заявок
- ✅ Фильтрация и поиск заявок
- ✅ Современный адаптивный интерфейс

## Установка и запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск приложения

```bash
python app.py
```

Приложение будет доступно по адресу: http://localhost:5000

## Использование

### Главная страница
- Просмотр статистики по заявкам
- Быстрый доступ к последним заявкам
- Быстрые действия для создания новых записей

### Заявки
- Создание новых заявок на снабжение
- Просмотр и редактирование существующих заявок
- Фильтрация по статусу и приоритету
- Обновление статусов с комментариями

### Поставщики
- Ведение базы поставщиков
- Контактная информация
- Связь с заявками

### Объекты
- Ведение базы строительных объектов
- Информация о менеджерах объектов
- Связь с заявками

## База данных

Приложение использует SQLite базу данных, которая создается автоматически при первом запуске. Файл базы данных: `supply_tracker.db`

## Технологии

- **Backend**: Flask, SQLAlchemy, WTForms
- **Frontend**: Bootstrap 5, Font Awesome
- **База данных**: SQLite
- **Язык**: Python 3.7+
